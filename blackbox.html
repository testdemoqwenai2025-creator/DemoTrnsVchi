Automotive Black Box

Circular buffer edge logging, crash-survivable storage, and automated synthetic re-simulation. The last 60 seconds of all sensor + control data is constantly captured in RAM; on trigger, it dumps to hardened flash for cloud re-simulation.

💾 Crash-survivable storage (hardened flash)
Trigger conditions:
  • ASIL-D safety goal violation (braking/steering failure)
  • Manual disengagement (driver override)
  • Crash detected (accelerometer spike)
  • Watchdog expiry on safety-critical subsystem
  • Operator-initiated dump (from this UI)
