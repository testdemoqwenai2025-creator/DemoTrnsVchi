Live Demo

Self-contained dynamic operations console — perception objects drift at 5 Hz, V2V mesh moves, watchdog timers tick, traffic-light phase changes. No backend, no socket, all client-side. Simulation runs in a dedicated Web Worker (offloaded from the main thread) so the UI never freezes even at high frequencies.

Phase 8 architectural improvements: (1) Dual-stream data ingestion — production vs synthetic streams are isolated at the type level so dev testing never contaminates real telemetry. (2) Decoupled Web Worker fabric — the simulation loop runs in assets/telemetry-worker.js, off the main thread. The main thread only does DOM updates. (3) Edge-case simulation — localization models GNSS blackout + IMU drift, perception models occlusion events, prediction models phantom-braking triggers, V2X models spoofed nodes.
